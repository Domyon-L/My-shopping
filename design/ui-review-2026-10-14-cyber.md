# 精品之城：星河赛博夜景与黑洞虫洞通道

## 本次范围

夜间入口、购物界面、模态面板与穿越通道的视觉优化。沿用当前公开 Site 与原 URL，白昼布局和商品内容保留。新增紫蓝星河 / 暗红星潮两种浏览器本地氛围偏好。

用户的“流血”一词未获得进一步说明，本次默认星河氛围保留流星，并提供暗红能量氛围供切换，没有将其写成血液实体或写入商品内容。

## 视觉与实现

- 夜间采用深空黑、冷青蓝、霓虹紫；暗红作为可选星云、光环和流星配色。增加细网格、角部高光、分层玻璃面板、较为利落的边框和按钮。
- 黑洞有不透光核心、光子环、倾斜旋转吸积盘与弯曲背面光弧。逐渐放大后交叉淡入虫洞。
- 虫洞通过逆深度环截面、沿深度移动的中心和螺旋纵向线表现空间感。星尘随动；商品分类符号仅作为低亮度外围元素。
- 这是艺术化视觉，几何不对应真实相对论解或观测数据。
- Canvas 和 CSS 均遵循减弱动态/关闭特效选项；静态 CSS 黑洞保证低动效模式仍有主题画面。
- 继续使用原0.5–3秒时长设置，默认1.5秒；窗口变化、后台暂停与恢复均不能更改一次进入所采用的时长。

## 验证

单元与DOM交互测试覆盖几何数值、黑洞到虫洞的阶段变化、320/390/1440视口参数、取消与跳过、期间改变窗口、后台暂停、氛围持久化、白昼样式隔离和原购物功能。当前没有control-browser；未作真实浏览器视觉或设备帧率测试。

商品目录与公开价格证据相对于第17版没有变化；仍846条展示记录和百元优先规则。
