# 精品之城 · Domyon 好物引力

公开站点：https://shopping.ldomyon69.chatgpt.site

首次进入显示独立的星空搜索入口。深空星点、北斗七星、白羊座和透视星流保留，入口与通道中的极光帘已移除。进入设置可调节 0.5–3 秒，步长 0.1 秒，默认 1.5 秒；计时、动画进度与最终跳转使用同一时长。外层精灵只在入口显示，购物页停止入口绘制。

购物页使用深海蓝或冷白钢蓝主题，采用单一蓝色强调。卡片统一显示参考价、价格日期和主要规格，主按钮打开站内详情。详情包含商品概览、完整规格、包装与使用限制、价格来源，原厂链接作为可选依据。手机从 320 px 起为双列卡片，筛选折叠；合格库存超过 24 件时可累积加载。支持浏览器本地收藏、最多三件对比和 CSV 导出。

## 商品与价格

截至 2026-10-13，展示 846 件商品：840 件恢复自原目录的历史参考价，6 件有近期人民币价格来源。另有 15 件缺少价格记录，暂不展示；1 条重复型号已合并。完整档案仍保留 862 条记录，不删除未展示商品的收藏 ID。

历史参考价保留原金额及 2026-09-14 / 2026-09-19 的原记录日期，不表示当前售价或已核实的型号、规格与包装。卡片和详情明确区分历史参考价与近期有来源参考价；无来源时不生成空链接，不填造资料。

有据精选仍要求资料与身份明确、人民币价格为正、有 HTTPS 报价来源、价格日期不晚于当前时间且未超过 30 天。尚无报价、异常价格、无效日期、合并记录与过复核期公开标价不能借收藏、分类或导出重新展示。

预算按价格区间中值匹配；默认纳入明确标注的历史参考价，可在更多筛选关闭。关闭后，预算和价格排序仅使用近期有效参考价，历史商品在无预算浏览中仍保留。

`catalog/reviewed-catalog.json` 保存全部档案，`dist/catalog-data.js` 保存可展示商品及归档 ID / 型号映射；`catalog/price-refresh.json` 与 `catalog/detail-content.json` 保存价格来源、具体版本和有依据的资料。此次未修改原价格、来源或观察日期；目录审核不等于实物质检。

## 浏览行为

手机底部“发现”、外层宠物“带我发现好物”和购物页品牌返回完整目录；“有据精选”范围单独显示有证据的商品。品牌只返回购物主页，不重新触发星空通道。搜索、分类、预算、场景、收藏与加载批次在返回主页时重置。

PC 保留上一版购物主页结构。手机保留双列商品、24 件起始批次及连续加载；顶部分类横向浏览，全部 11 个分类都可访问。重复的英雄区筛选入口在手机隐藏，精选与新品从列表范围切换。常用手机按钮至少 44 px 高，搜索字体 16 px；底部导航与对比条考虑安全区。

## 维护与检查

```sh
npm ci
npm run build
npm test
```

生产入口为 `catalog/index.template.html`；`scripts/refresh-catalog.mjs` 生成目录，`scripts/build-static.mjs` 生成 HTML 与内容哈希资源。编辑稳定的 `dist/` 源文件，勿直接修改 `dist/assets/`。当前卡片、详情和主题样式由最后加载的 `refined.css` 控制；`tech.css`、`storefront.css` 保留入口及基础交互样式。动画源为 `experience.mjs` / `night-sky.mjs`，星群轮廓源为 `constellations.mjs`。无新增前端框架依赖。

39 项 Node / jsdom 检查涵盖价格与身份门禁、所有公开范围、导出、分类计数、收藏与对比、详情章节和来源链接、实际目录的手机累积加载、入口隔离、时长及取消、精灵拖动、星流绘制和有效坐标。新增回归用例先复现“发现 / 宠物只出现 6 件”及品牌保留零结果筛选的问题，再验证修复。

CSS 已做语法与响应式规则检查。这些检查不等于像素布局、浏览器帧率或实体触屏测试。托管环境缺少指定的 control-browser 能力；此前 BrowserAct 启动返回 Error 230305，本次没有重复尝试失败服务。2026-10-13 Figma MCP 仍返回 Starter 额度耗尽；原可编辑设计 https://www.figma.com/design/S0oE0Xi71chU7RpN5MK78h 暂未同步此次变化。

每次完成验证后发布到同一公开 shopping 链接，手机和桌面共用版本。静态资源带内容哈希，刷新或重新打开后加载新版；已打开页面保留当前运行状态。
