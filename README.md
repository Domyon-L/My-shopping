# 精品之城 · Domyon 好物引力

公网网站：https://shopping.ldomyon69.chatgpt.site

公开源码仓库：https://github.com/Domyon-L/My-shopping

第22版：购物主内容始终占满可用宽度，移除居中宽度上限与外围留白；侧栏展开时只保留它实际占用的空间。深浅主题、分类、搜索和空结果共用此布局。顶部搜索继续固定，筛选区随内容滚动，不再悬浮遮住商品。

搜索支持日常同义词、连续中文关键词、品牌中英文别名、全半角及型号分隔符。“裤子”可找到现有32件外穿裤装，“短裤”等具体查询保持具体范围；“优衣库裤子”“100元以内裤子”可组合查找。顶部搜索、入口搜索及联想结果共用匹配与预算规则；新顶部查询会清除旧分类、场景、收藏范围等限制，结果区显示当前搜索范围。中文输入法组词期间不刷新结果。默认搜索按相关度排序，同等相关度沿用百元优先；用户明确选择价格排序时保留该排序。未识别关键词不会被丢弃，也不使用无关商品凑结果。以上是本地词表与字段匹配，不是任意自然语言理解。

当前界面更新：商品分类与预算入口放在左侧导航，购物搜索栏固定顶部。电脑上，鼠标留在侧栏区域、按住鼠标或持续点击时均保持展开；离开侧栏且停止操作3秒后完全消隐，不留下分类图标。将鼠标移到屏幕左缘即可恢复，不会抢走搜索焦点。键盘焦点留在侧栏时也保持展开；手机保留菜单与底部分类入口及抽屉焦点约束。进入网页仍先显示独立的星空入口，通道可设0.5–3秒。

黑洞通道加入前亮后暗的倾斜吸积盘、独立透镜光弧与不被光带遮挡的暗核，再进入偏轴弯曲、带螺旋轨道和移动光带的虫洞。原有跳过、取消、动效开关和计时保持可用。这是装饰性视觉表现，不是物理模拟。

## 商品目录

2026-10-14批次完成后共有1000件在展记录：160件有近期人民币价格来源，840件为原目录的历史参考价、型号与现价待核验。本批新增154个独立型号，139款参考价不超过100元，15款附有具体用途的加预算理由。完整档案1016条，包括15条未核价隐藏记录及1条合并记录；不删除原收藏ID。

来源与价格保留真实观察日期，不因重新构建而改成当天。资料核验不代表实物测试或质量评级；品牌代表作仅比较所列同品牌、同品类、特定用途的候选。首批4个品牌有6种用途的选择，其余品牌可搜索浏览，证据不足时不提供首选结论。

`catalog/reviewed-catalog.json`保存完整档案，`dist/catalog-data.js`保存当前可展示记录。`catalog/price-refresh.json`、`catalog/purchase-evidence.json`与`catalog/evidence-*.md`保存价格、购买建议与资料证据。近期公开标价超过30天须复核；历史参考价保留原口径和日期。

主分类按生活用途整理为：清洁纸品、家居日用、餐厨水具、个护美妆、服饰鞋包、学习办公、数码家电、运动户外、食品饮品、出行工具、玩具文娱、健康用品。参考国家统计局消费分类及宜家公开商品分区，再按现有目录做编辑归类；这12类不是官方分类标准或用户调查结论。分类研究、完整映射和例外见`catalog/taxonomy-research-v21.md`及`catalog/taxonomy-proposal-v21.json`。每条记录只有一个主类，跨用途通过搜索与场景发现；健康用品保留原有待核验限制。旧兴趣设置迁移到对应用途，保留原值快照。此次只改分类及旧分类留存字段，未刷新价格、来源日期或审核状态，核对结果见`catalog/taxonomy-integrity-v21.json`。

## 使用与外观

搜索、分类、预算、场景、收藏、最多三件对比及CSV导出均在浏览器内使用。商品卡片无图片或占位预览，统一显示参考价格、日期与规格，点击打开站内详情，原厂链接作为详情内的资料依据。

黑夜使用星河赛博朋克配色，黑洞吸积盘、虫洞光弧、粒子与流星构成动态背景；白昼使用暖纸色与冰蓝配色。尊重浏览器保存的主题、预算、兴趣、动效及最近浏览偏好。宠物只在外层入口显示。手机从320px起保留双列商品，24件起始，可累积加载。

## 发布与同步

每次完成更新与验证后，发布到原公网网站，并同步到`Domyon-L/My-shopping`的`main`分支。两个平台保留各自的提交历史，GitHub同步采用正常提交，不强制覆盖分支。GitHub Actions执行构建与回归检查。

`archives/shopping_latest_source.zip`是本次源文件快照，校验值和文件数量见`archives/SHA256.txt`。快照排除Git元数据、依赖缓存与`archives/`本身，避免递归打包；源码以仓库根目录的最新文件为准。根目录旧`site-*.tar.gz`为保留的历史部署归档，不是当前版本。
